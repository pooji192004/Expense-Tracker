Expense Tracker

Track your daily expenses from the terminal — simple, fast, and saves data forever!

Built with Python + SQLite | No extra installation needed

 What Can It Do?
#FeatureDescription
1. Add ExpenseSave category, description & amount 
2. View AllSee every expense in a neat table
3. Category SummaryKnow where your money is going
4. Monthly ReportFilter expenses by any month
5. DeleteRemove any expense by ID

 How to Run
Step 1 — Make sure Python is installed
bashpython --version
Step 2 — Run the file
bashpython expense_tracker.py

 No pip install needed — everything is built into Python!


 How Data is Stored
